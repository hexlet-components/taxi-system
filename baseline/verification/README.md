# Проверка исходного стенда

Стенд проверен 18 ноября 2026 года на macOS arm64 с Docker Desktop. Команда `pnpm test` создала отдельный проект Compose и завершилась с девятью успешными проверками без пропусков. Общая длительность составила 74,2 секунды. [Вывод прогона](./acceptance.txt) содержит названия и длительности сценариев.

Проверены оба экземпляра монолита, запись поездки и фоновых работ одной транзакцией, логическая репликация, построение сводки и доставка уведомления. Повтор создания оставил одну поездку, одно событие и одно задание. Отклонённое создание не оставило фоновых работ.

Остановка консьюмера сохранила прежнюю сводку и возможность создания поездки. После запуска новая поездка появилась в сводке. При остановленном Kafka событие сохранилось в outbox и было опубликовано после восстановления брокера. Отказ уведомлений не задерживал создание и построение сводки. После потерянного ответа и перезапуска исполнителя получатель сохранил один результат с повторным обращением. Повтор старого события не вернул сводку к прежнему статусу.

Проверка типов, oxlint и oxfmt прошли. Код и файлы каталога monolith не изменялись. Контейнеры и тома проверяющего проекта удалены. Результат относится к малому локальному опыту, без проверки отказа облачной зоны, сохранности при потере машины и нагрузочной производительности.
