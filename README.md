# Сервис такси

Учебный проект программы по проектированию систем Хекслета. Один сервис развивается на протяжении четырёх курсов.

| Курс | Каталог |
| --- | --- |
| Монолитное приложение | [monolith](./monolith) |
| События и стриминг | Материалы появятся по мере разработки курса |
| Распределённая система | Материалы появятся по мере разработки курса |
| Глобальная система | Материалы появятся по мере разработки курса |

Сейчас репозиторий содержит файлы для экспериментов из курса о монолитном приложении. Реализации HTTP API пока нет.

## Материалы монолитного приложения

| Файл | Назначение |
| --- | --- |
| [schema.sql](./monolith/database/schema.sql) | Базовые таблицы пассажиров, водителей, поездок и истории |
| [seed.sql](./monolith/database/seed.sql) | Данные для исследования индексов |
| [read-load.js](./monolith/load-testing/read-load.js) | Сценарий нагрузки k6 для чтения подготовленного HTTP-адреса |
| [nginx.conf](./monolith/nginx/nginx.conf) | Локальный балансировщик перед двумя экземплярами приложения |

## База данных

Потребуются PostgreSQL и клиентские команды `createdb` и `psql`. Параметры подключения задаются через `PGHOST`, `PGPORT`, `PGUSER` и другие настройки клиента.

Из каталога репозитория создайте пустую учебную базу и загрузите схему.

```bash
createdb taxi_development
psql -d taxi_development -v ON_ERROR_STOP=1 -f monolith/database/schema.sql
```

В рамках подготовки базы загрузите учебный набор поездок. Скрипт удалит её текущие данные и сбросит счётчики идентификаторов перед загрузкой.

```bash
psql -d taxi_development -v ON_ERROR_STOP=1 -f monolith/database/seed.sql
```

Схема содержит базовые связи. Дополнительные ограничения и индексы вводятся в уроках по мере разбора соответствующих задач.

## Нагрузка и балансировка

Сценарий k6 требует работающий тестовый HTTP-сервер. Настройки запуска и проверки ответа находятся в [сценарии](./monolith/load-testing/read-load.js).

Конфигурация nginx принимает запросы на `127.0.0.1:8080` и передаёт их серверам на портах `8001` и `8002`. Запускайте её с отдельным временным каталогом для PID и журналов согласно инструкциям урока.
