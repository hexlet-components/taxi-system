# Проверка примера

Запуск выполнен 17 ноября 2026 года по America/New_York, 18 ноября по UTC. Окружение состояло из macOS arm64, Docker Desktop с Docker 29.9.3 и Node.js 26.13.1. Образы собирались локально и в реестр не отправлялись.

## Бронирование и перенос

Команда `pnpm test` завершилась с 12 успешными сценариями и без пропусков. [Сохранённый вывод](./acceptance.txt) содержит названия проверок. Общая длительность составила 54,5 секунды, включая подготовку и удаление отдельного проекта Compose.

Проверены два владельца данных, идемпотентное создание, конкурентное назначение, восстановление outbox и платёжного результата, отмена с поздним резервом, незавершённая компенсация, окончательное освобождение до резервирования и ограниченные повторы. Прерванный перенос продолжен новым контроллером. Проверены все ранее созданные поездки, отказ старому поколению и маршруту, сохранность новой поездки после повтора установки снимка, обратный перенос и работа другого города при остановке одного владельца.

Проверка типов, oxlint и oxfmt прошли. Markdown и блоки команд проверены средствами кита. Орфографическая проверка новых инструкций завершилась без находок. Внешние ссылки проверены; внутреннее имя `payments:8080` исключалось только для этого запуска проверки ссылок, его методы выполнялись в приёмочных сценариях.

## Переключение PostgreSQL

Все четыре опыта выполнены на чистых состояниях. [Истории](./failover) содержат ответы клиентов, снимки таблиц, события и идентификаторы образов.

| История | Категория | Запуск, с | Переключение, с |
| --- | --- | --- | --- |
| sql-fencing-1 | safe-fencing | 11,03 | Не выполнялось |
| sync-network-1 | safe-with-running-controller | 18,47 | 21,68 |
| async-loss-1 | acknowledged-data-loss | 12,73 | 21,69 |
| controller-pause-1 | unsafe-stale-primary | 9,43 | 22,60 |

Проверяющий скрипт подтвердил четыре ожидаемые категории и отклонил отрицательные контрольные примеры. Для повторной проверки сохранённых историй из каталога _distributed_ Docker не нужен.

```bash
node failover/verify.ts verification/failover
```

`acknowledged-data-loss` и `unsafe-stale-primary` обозначают обнаруженные нарушения сохранности. Они не подтверждают безопасность этих конфигураций. Отказ облачной зоны, аппаратный watchdog, нагрузочная производительность и подключение кластера Patroni к приложению бронирования в этом запуске не проверялись. Временные контейнеры и тома обоих прогонов удалены.
