# События и стриминг

Запускаемые примеры второго курса программы по проектированию систем. Каждый каталог содержит программы, зависимости, окружение Docker Compose и инструкцию по запуску.

| Каталог | Что проверяет пример |
| --- | --- |
| [async-models](./async-models) | Распределение задания между исполнителями, независимые подписки RabbitMQ и чтение истории двумя группами Kafka |
| [kafka](./kafka) | Выбор партиции по ключу и порядок записей двух поездок |

Для запуска нужны Docker и Docker Compose. Команды выполняются из каталога выбранного примера. Каждый пример использует собственное имя проекта Compose, поэтому его окружение можно остановить отдельно. Программы печатают результаты передачи и чтения сообщений, которые разбираются в уроках.
