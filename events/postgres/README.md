# SQL-опыты PostgreSQL

Окружение дополняет уроки «Доставка и правильность обработки» (`delivery-guarantees`) и «Получение изменений из базы» (`database-changes`). Для воспроизведения SQL из уроков подходит отдельная база PostgreSQL. Этот Compose запускает проверенный образ PostgreSQL 18.6 и не публикует порт на хост. Учебные учётные данные используются только внутри контейнера.

Команды выполняются из этого каталога. На компьютере установлены Docker и Docker Compose.

```bash
docker compose up -d --wait
docker compose exec postgres psql -U student -d streaming
```

В открывшемся psql можно выполнить SQL-блоки одного урока по порядку. Для временных таблиц все блоки выполняются в одной сессии. Для примера двух транзакций открываются два терминала и в каждом выполняется команда подключения. Находящиеся в учебной базе постоянные таблицы сохраняются при выходе из psql.

Повтор опыта с временными таблицами начинается в новом соединении. Повтор опыта с постоянными таблицами проводится в новой учебной схеме или после очистки ровно тех таблиц, которые созданы примером.

После завершения всех опытов окружение удаляется из того же каталога.

```bash
docker compose down -v
```

Флаг -v удаляет том этой учебной базы. Данные других Compose-проектов эта команда не затрагивает.
