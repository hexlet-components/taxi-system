# Когда можно показать квитанцию

Событие сообщает о завершении поездки в версии 6. Пассажир открывает квитанцию в другом регионе. Пример проверяет, можно ли показать ему уведомление, если в местной копии видна версия 5, 6 или 7. В этой модели номер версии растёт, а квитанция остаётся доступной после завершения поездки.

В каталоге три варианта программы. Из каталога _global/receipt_ выполните одну команду для установленного у вас языка.

| Язык | Команда |
| --- | --- |
| Go | `go run main.go` |
| Java | `java Receipt.java` |
| Python | `python3 receipt.py` |

Для версии 5 программе приходится ждать. Как только поездка достигла требуемой версии, проверка проходит.

```console
ждать
готово
готово
```
